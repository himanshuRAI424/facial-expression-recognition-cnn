# Facial Expression Recognition Using CNN and OpenCV

## About the Project

This project is a real-time facial expression recognition system using a Convolutional Neural Network (CNN) and OpenCV.

The system uses a webcam to detect faces and classify facial expressions in real time.

## Technologies Used

- Python
- TensorFlow
- Keras
- CNN
- OpenCV
- NumPy
- Scikit-learn

## Features

- Real-time face detection
- Facial expression recognition
- CNN-based classification
- Live webcam detection

## Project Files

- `face_expression_detection.ipynb` - CNN model training
- `3_live_webcam_detect.py` - Real-time webcam detection

## Workflow

Webcam → OpenCV → Face Detection → Preprocessing → CNN → Emotion Prediction
