# Facial Expression Recognition Using CNN and OpenCV

## About the Project
This project is a real-time facial expression recognition system using a Convolutional Neural Network (CNN) and OpenCV. The system captures live video from a webcam, detects faces, and predicts the facial expression in real time.

## Technologies Used
- Python
- TensorFlow / Keras
- CNN
- OpenCV
- NumPy
- Scikit-learn
- Matplotlib

## How It Works
Webcam → OpenCV Face Detection → Face Preprocessing → CNN → Emotion Prediction

## Features
- Real-time face detection
- CNN-based emotion classification
- Live webcam prediction
- Facial expression visualization

## Project Files
- `face_expression_detection.ipynb` – CNN training and analysis
- `3_live_webcam_detect.py` – Real-time webcam detection
